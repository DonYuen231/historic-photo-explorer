# Scoring rubric

Each description gets four scores from 1 to 5. Score each one on its own:

| Score | Question it answers |
| --- | --- |
| **Accuracy** | Is what it says true? |
| **Completeness** | Does it leave out anything important that's in the picture? |
| **Usefulness to a blind reader** | Is it told in a way a listener can follow? |
| **Matches reference** | Does it get across what the LoC cataloger wrote? |

A description can be fully accurate but incomplete, or complete but badly ordered. Each problem lowers only the score that covers it, except that a visible thing the reference also names (for example, a dog in the room) counts against both Completeness and Matches reference.

## 1. Accuracy

*Is everything it says actually in the photo or in the catalog record?*

Only count what the description **claims**. Leaving something out is covered by Completeness, not here.

A guess that is clearly hedged ("possibly", "appears to be") is not a slip, **with one exception:** a hedged guess that names a person, place or event, where the catalog record says otherwise, counts as if it were stated. A listener hears "likely the 1919 race riot" as the answer, so if the record says the photo shows something else, that's an error.

| Score | Meaning | Example from this eval |
| --- | --- | --- |
| **5** | Every claim is visible in the image or stated in the catalog record (title, date). | Cuchifrito sign: every word and object it mentions is there, down to the RONMAR sticker. |
| **4** | One minor slip: a small detail stated as fact that can't be checked or is slightly off, **or** a date/period that goes against the catalog date with no visible evidence. The main subject is right. | Tubman (v1): gives "late 1860s to 1870s" against a catalog date of 1895, with no evidence. |
| **3** | Two or more minor slips, **or** one clearly wrong claim about a secondary detail. The main subject is still right. | None in this eval after review. (Family portrait v1 was first scored 3 here, then raised to 4: "several adults" for two is a slip, "multiple generations" is technically true.) |
| **2** | A wrong claim about the main subject, **or** it links the photo to a person or event the record contradicts (hedged or not). | Squad car (v1): "likely connected to the July 1966 West Side unrest"; the record says it was a gang fight on the northwest side. |
| **1** | Mostly describes things that aren't there. | None in this eval. |

## 2. Completeness

*Does it mention everything important that's in the picture?*

This is about what's **in the image**: people, animals, objects, the action, the setting and any text. Names, dates and history that you can't see are covered by Matches reference, not here.

- **Important elements:** every person and animal (with a rough count when there are only a few), the main objects, what is happening, the setting, and any large text such as a title or sign.
- **Minor elements:** smaller background objects, small text, and details of shape, clothing or condition that a sighted viewer would still notice.

Rules:

- Use the reference summary as evidence of what's in the photo. If the cataloger says there is a horse in the street, there is one.
- A **low-resolution image doesn't excuse a miss.** If the horse isn't mentioned, the listener doesn't learn about them, whatever the reason. Saying "detail can't be made out" is honest, but it doesn't count as covering the missed element.
- A small fraction of a crowd, or one of dozens of similar items, doesn't need to be listed. "Rows of awnings" covers the awnings.

| Score | Meaning | Example from this eval |
| --- | --- | --- |
| **5** | Mentions every important element and nearly every minor one. | Castle Clinton: the sign, its full text, the board fence and the stone fort behind it. |
| **4** | Every important element; misses 1–2 minor ones. | Bloom Jeweler: doesn't say that the lamp and round sign together form the shape of a diamond ring. |
| **3** | Misses one important element, **or** 3 or more minor ones. | Squad car (v1): misses the second damaged police car, and that the burning car is on its side. |
| **2** | Misses two or more important elements, **or** a key part of the main subject. | Family portrait: no dogs, and no count of the people (two fathers, three sons). |
| **1** | Misses the main subject entirely. | None in this eval. |

## 3. Usefulness to a blind reader

*If a screen reader read it aloud, could the listener follow it easily?*

This is about **how** it's told, not **what** it includes (that's Completeness). Imagine hearing it once, start to finish, with no way to skim. The four common problems:

- **Filler** at the start ("no text is visible on the image", "identified by the catalog title").
- **Order:** secondary detail (clothing, the print's mat or layout) comes before the main point or the setting.
- **Buried text:** a title, caption or sign is read out only in the "notable details" list, not in the description.
- **Too long:** so dense that the main points get lost.

| Score | Meaning | Example from this eval |
| --- | --- | --- |
| **5** | Main subject in the first sentence, in plain words. Any visible text is read out early in the description. None of the four problems. | Rancho Luna mural: names the club, reads both signs, then describes the painting. |
| **4** | One of the four problems. | Beach crowd (v2): good description, but it opens with a sentence about there being no legible text. |
| **3** | Two of the four problems. | Reading map (v1): banner text only in the details list, and very dense. |
| **2** | Three or more of the problems, **or** confusing wording that leaves the listener unsure what the main subject is. | None in this eval. |
| **1** | Unusable: no clear subject, or mostly filler. | None in this eval. |

## 4. Matches reference

*How much of what the LoC cataloger wrote ("Photograph shows…") does the description also convey?*

Split the reference into facts:

- **Key facts:** the main subject as the reference states it (including the person's name, if it names one) and the main action.
- **Secondary facts:** everything else, such as place names, background objects, other text, or the cause or context.

Rules:

- A list in the reference (for example, a list of business names) counts as **one** fact. If the description covers part of it, it counts as covered.
- A reference fact that is **wrong** is ignored. For example, the cataloger wrote "purse" for what is clearly a wicker basket.
- A fact that can't be seen in the image **still counts**. This score measures how much of what a human expert conveys gets through, so missing Muhammad Ali's name lowers it even though the thumbnail is too small to recognize him.

| Score | Meaning | Example from this eval |
| --- | --- | --- |
| **5** | Covers all key facts and all secondary facts. | Castle Clinton: transcribes the whole sign, as the reference does. |
| **4** | Covers the key facts; misses or contradicts 1–2 secondary facts. | Chestnut Street: gets the street and two signs, misses "Law Books" and "Eagle Hotel". |
| **3** | Covers the key facts; misses or contradicts 3 or more secondary facts. | Family portrait: gets "family in a room", misses the two fathers, three sons and two dogs. |
| **2** | Misses a key fact, or only partly gets it. | Ali signing autographs: "a man signing autographs", not named. |
| **1** | Contradicts a key fact. | Paddy Murray (v1): says the stretcher carries "presumably the victim"; the reference says it's the gang's lawyer. |
