# Scoring rubric

Each description gets three scores from 1 to 5. Score each one on its own: a description can be fully accurate but not very useful, or useful but missing facts from the reference.

## 1. Accuracy

*Is everything it says actually in the photo or in the catalog record?*

Only count what the description **claims**. Leaving something out doesn't lower accuracy (the other two scores cover that). A guess that is clearly hedged ("possibly", "appears to be") is not a slip.

| Score | Meaning | Example from this eval |
| --- | --- | --- |
| **5** | Every claim is visible in the image or stated in the catalog record (title, date). | Cuchifrito sign: every word and object it mentions is there, down to the RONMAR sticker. |
| **4** | One minor slip: a small detail stated as fact that can't be checked or is slightly off, **or** a date/period that goes against the catalog date with no visible evidence. The main subject is right. | Tubman (v1): gives "late 1860s to 1870s" against a catalog date of 1895, with no evidence. |
| **3** | Two or more minor slips, **or** one clearly wrong claim about a secondary detail. The main subject is still right. | Family portrait (v1): "multiple generations" and "several adults" (there are two). |
| **2** | A wrong claim about the main subject, **or** it links the photo to a person or event the record contradicts. | Squad car (v1): ties it to "the July 1966 West Side unrest"; the record says it was a gang fight on the northwest side. |
| **1** | Mostly describes things that aren't there. | None in this eval. |

## 2. Usefulness to a blind reader

*If this were read aloud by a screen reader, would the listener quickly get a clear picture?*

The four common problems:

- **Filler** at the start ("no text is visible on the image", "identified by the catalog title").
- **Order:** secondary detail (clothing, background) comes before the main point or the setting.
- **Buried text:** a title, caption or sign is read out only in the "notable details" list, not in the description.
- **Too long:** so dense that the main points get lost.

| Score | Meaning | Example from this eval |
| --- | --- | --- |
| **5** | Main subject in the first sentence, in plain words. Any visible text is read out early in the description. None of the four problems. | Rancho Luna mural: names the club, reads both signs, then describes the painting. |
| **4** | One of the four problems. | Beach crowd (v2): good description, but it opens with a sentence about there being no legible text. |
| **3** | Two of the four problems, **or** a low-resolution photo where the description is honest but gives the listener little. | Reading map (v1): banner text only in the details list, and very dense. |
| **2** | Vague or hard to follow; the listener wouldn't get a clear picture of the main subject. | Family portrait (v1): "several adults… a few young children", no count, no clear picture. |
| **1** | Unusable: no clear subject, or mostly filler. | None in this eval. |

## 3. Matches reference

*How much of what the LoC cataloger wrote ("Photograph shows…") does the description also convey?*

Split the reference into facts:

- **Key facts:** the main subject as the reference states it (including the person's name, if it names one) and the main action.
- **Secondary facts:** everything else, such as place names, background objects, other text, or the cause or context.

Rules:

- A list in the reference (for example, a list of business names) counts as **one** fact. If the description covers part of it, it counts as covered.
- A reference fact that is **wrong** is ignored. For example, the cataloger wrote "purse" for what is clearly a wicker basket.
- A fact that can't be seen in the image **still counts**. This score measures how much of what a human expert conveys gets through, so missing Muhammad Ali's name lowers it even though the thumbnail is too small to recognize him.

| Score | Meaning | Example from this eval |
| --- | --- | --- |
| **5** | Covers all key facts and all secondary facts. | Castle Clinton: transcribes the whole sign, as the reference does. |
| **4** | Covers the key facts; misses or contradicts 1–2 secondary facts. | Chestnut Street: gets the street and two signs, misses "Law Books" and "Eagle Hotel". |
| **3** | Covers the key facts; misses or contradicts 3 or more secondary facts. | Family portrait: gets "family in a room", misses the two fathers, three sons and two dogs. |
| **2** | Misses a key fact, or only partly gets it. | Ali signing autographs: "a man signing autographs", not named. |
| **1** | Contradicts a key fact. | Paddy Murray (v1): says the stretcher carries "presumably the victim"; the reference says it's the gang's lawyer. |
